# 安全防护

四层 WAF、JWT 认证、传输加密和速率限制子系统。

## 结构

```
安全防护/
├── auth.go           # JWT 认证 + bcrypt 密码 + SMTP 邮件
├── waf.go            # 四层 WAF 引擎
├── ratelimit.go      # 令牌桶速率限制（全局 + 每 Consumer + 每 IP）
├── middleware.go      # 中间件链（CORS/认证/速率限制/本地限制）
├── encryptor.go      # AES-256-GCM 加密器（密钥存储加密）
└── transport_encryption.go  # 传输加密（中继载荷加密）
```

## 关键文件

| 文件 | 目的 |
|------|------|
| `waf.go` | `WAFEngine` 四层防护：IP 封禁 → IP 黑名单 → UA 过滤 → 速率限制 → 路径保护 → 内容关键词 |
| `auth.go` | `Auth` 结构：JWT 生成/验证、bcrypt 密码、协作账户、密码重置 |
| `middleware.go` | 装饰器模式中间件链：`withAuth`/`withProxyAuth`/`withFederationAuth`/`localOnly` |
| `ratelimit.go` | `RateLimiter`（令牌桶）、`GlobalRateLimiter`、`rateLimitByIP`（每 IP 固定窗口） |

## WAF 四层防护

| 层级 | 检查内容 | 配置项 |
|------|----------|--------|
| Layer 0 | 动态 IP 封禁 | `waf_ban_duration` |
| Layer 1 | IP 黑名单 | `waf_ip_blacklist` |
| Layer 2 | User-Agent 过滤 | `waf_ua_blacklist` |
| Layer 3 | 每 IP 速率限制 | `waf_rate_limit_rps`/`waf_rate_limit_burst` |
| Layer 4 | 路径保护 | `waf_blocked_paths` |
| Layer 5 | 内容关键词 | `waf_content_keywords` |

WAF 默认启用。速率限制设为 `0` 时禁用。

## 认证中间件链

```
请求 → corsMiddleware → requestLogMiddleware → concurrencyMiddleware
     → [路由匹配]
     → withProxyAuth（API Key 认证）
     → wafMiddleware（WAF 检查）
     → rateLimitMiddleware（全局 + 每 Consumer 速率限制）
     → 业务 Handler
```

## 速率限制架构

| 组件 | 作用 | 容量上限 |
|------|------|----------|
| `RateLimiter` | 令牌桶，单实例 | N/A |
| `GlobalRateLimiter` | 全局 + 每 Consumer | consumers map 10000 条 |
| `rateLimitByIP` | 每 IP 固定窗口 | ipRateLimiters map 10000 条 |
| WAF `ipLimiters` | WAF 专用每 IP | 10000 条 |

所有无界 map 均有 LRU 清理机制，超容量时淘汰 10 分钟未活跃条目。
