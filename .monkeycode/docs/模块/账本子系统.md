# 账本子系统

贡献记录、信任评分、IPFS 镜像和能力验证。位于 `ledger/` 子包。

## 结构

```
ledger/
├── types.go                  # 核心类型定义
├── trust_manager.go          # 信任级别管理
├── gossip_ledger.go          # Gossip 账本 + 签名交易链
├── free_ledger.go            # 免费贡献账本
├── capability_verifier.go    # 能力验证
└── ipfs_client.go            # IPFS 网关客户端
```

## 关键文件

| 文件 | 目的 |
|------|------|
| `types.go` | 核心类型：`ContributionRecord`、`TrustRecord`、`SignedTransaction`、接口定义 |
| `gossip_ledger.go` | 追加式贡献账本：Ed25519 签名、哈希链、跨节点合并、IPFS 镜像 |
| `trust_manager.go` | 信任级别计算：New → Low → Medium → High → Verified |
| `ipfs_client.go` | 零依赖 IPFS 客户端：使用公共网关（ipfs.io, dweb.link）存储/检索 |

## 签名交易链

`SignedTransaction` 是账本的核心数据单元，通过哈希链保证不可篡改：

```go
type SignedTransaction struct {
    TxID        string    // 交易 ID
    PrevHash    string    // 前一笔交易的哈希（链式结构）
    Type        string    // contribution / consumption / penalty
    NodeID      string    // 节点 ID
    Amount      int64     // 数量
    Timestamp   int64     // 时间戳
    Signature   string    // Ed25519 签名
    Hash        string    // 本交易的 SHA-256 哈希
}
```

### 关键方法

| 方法 | 描述 |
|------|------|
| `AppendTransaction(tx)` | 追加交易，自动链接前一笔哈希 |
| `GetTransactionChain()` | 返回完整交易链 |
| `DeriveBalance(nodeID)` | 从链中推导节点余额 |
| `VerifyChain()` | 验证整条链的哈希完整性 |

## 信任级别

| 级别 | 评分范围 | 描述 |
|------|----------|------|
| New | 0 | 新加入节点 |
| Low | 1-30 | 初步验证 |
| Medium | 31-60 | 稳定贡献 |
| High | 61-90 | 高可靠节点 |
| Verified | 91-100 | 完全验证节点 |
