# 数据持久化

JSON 文件存储、AES-256-GCM 加密、HMAC-SHA256 完整性校验和 Debounced 写入。

## 结构

```
数据持久化/
├── config.go           # Config（debounced JSON 持久化）
├── encryptor.go        # Encryptor（AES-256-GCM 加密/解密）
├── data_integrity.go   # HMAC-SHA256 完整性校验
└── tracker.go          # Tracker（用量追踪 + 批量写入）
```

## 关键文件

| 文件 | 目的 |
|------|------|
| `config.go` | 持久化键值存储：3 秒 Debounce 写入、环境变量回退、敏感字段加密 |
| `encryptor.go` | 加密器：密钥来源优先级（环境变量 → 文件 → 临时密钥）、字段级加密/解密 |
| `data_integrity.go` | `saveWithIntegrity()`/`loadWithIntegrity()`：HMAC 签名 + 原子写入 |

## 持久化文件清单

| 文件 | 内容 | 加密 | 完整性 |
|------|------|------|--------|
| `data/config.json` | 全局配置 | 敏感字段加密 | Debounced |
| `data/providers.json` | Provider 列表 | API Key 加密 | - |
| `data/admin.json` | 管理员凭证 | 密码哈希 bcrypt | - |
| `data/usage.json` | 用量记录 | 无 | 批量写入 |
| `data/federation_pool.json` | 信任池 | 无 | HMAC |
| `data/.key` | 加密密钥 | - | 文件权限 0600 |
| `data/.node_key` | 节点私钥 | AES 加密 | - |
| `data/guest_keys.json` | 访客密钥 | 无 | 定期保存 |

## 写入路径

### Config Debounced 写入

```
Set(key, value) → 更新内存 data → 标记 dirty → 信号 dirtyCh
  → debounceWriter() → 等 3 秒 → 合并多次修改 → doSave()
    → 加密敏感字段 → saveWithIntegrity() → 原子写入（.tmp → rename）
```

### Tracker 批量写入

```
Record() → 追加到内存 ring buffer（max 5000）→ dirtyCount++
  → 每 3 秒 或 dirtyCount >= 50 → flushToDisk()
```

### Encryptor 密钥来源优先级

1. 环境变量 `ENCRYPTION_KEY`
2. 文件 `data/.key`（48 字节 base64）
3. 临时生成（每次重启失效，打印 Error 级别警告）
